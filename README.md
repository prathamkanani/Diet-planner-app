# Diet Planner
A diet planning app that helps users plan meals, track nutrition, and build healthy eating habits.

## Overview
The Diet Planner App allows users to create personalized diet plans based on their preferences and lifestyle.  
It simplifies meal planning, calorie tracking, and nutritional awareness in one place.

## Project Scope
- User authentication
- Asking for basic user information
- Daily meal planning
- Personalized diet plan
- Calorie and nutrition tracking
- Progress tracking(weight)

## Features
- User profile setup
- Custom meal plans
- Nutrition & calorie tracking
- Daily reminders
- Progress visualization

## Architecture & Tech Stack
- **Frontend:** Flutter
- **State Management:** Bloc
- **Backend/Database:** Supabase
- **Auth:** Google & Email Authentication
- **Architecture:** Clean Architecture
